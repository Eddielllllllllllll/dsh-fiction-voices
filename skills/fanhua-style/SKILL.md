# 繁花笔法

《繁花》的厉害处，不在沪语，在**克制**。金宇澄写两个女人为一个男人争了三十年，全篇没有一句"她爱他"，只写吃饭、写谁坐哪个位子、写一句话说完之后"不响"。

先记住一句：**能不说的，全都不说。说出来的，都是不重要的。**

## 一、五条核心气质

1. **市井即史诗。** 不写大人物，写弄堂里的阿姨、饭店的领班、跑单帮的男人。时代从他们脚底下流过去，他们只管吃饭。
2. **旁观者视角。** 叙述者像一个坐在弄堂口摇蒲扇的老人，什么都看见，什么都不评判。不解释动机，不点破关系，不给结论。
3. **暧昧高于爱情。** 男女之间不写"爱"，写谁给谁留了个位子、谁替谁挡了一杯酒、谁在楼下等了一个钟头没上去。
4. **物承载一切。** 一件旗袍、一只大闸蟹、一包牡丹烟、一张电车票——情绪全在这些东西里，不在形容词里。
5. **时间并置。** 一九六〇年代和一九九〇年代两条线交叉着走，读者自己拼。拼出来的那个东西，才是小说的意思。

## 二、句法技术

- **短句白描为主。** 《繁花》的句子短、实、干净，几乎不用形容词堆叠，靠名词和动词自己立住："沪生不响。蓓蒂也不响。两个人吃茶。"
  - ⚠️ 若所写项目要求"长句为主、短句≤8%"，则把繁花短句改造成**长句的呼吸点**：长句铺开环境与人物，短句只在两个人都不说话的瞬间落一句，全章不超过两处。
- **名词堆叠，不解释。** "台面上是四冷盘、四热炒、一大砂锅、两瓶绍兴酒。"读者自己知道这是什么场面。
- **对话用"讲"，不用"说"。** "蓓蒂讲，侬晓得伐，现在的人，勿要太精明。"
- **方言控制在每章五处以内，永不解释。** 侬、阿拉、勿要、晓得伐、阿是、蛮好、邪气、老卵。多了成方言词典，少了没味道。
- **价钱写到个位。** "一块两角""三角五分""十二块洋钿"——数字一具体，年代就出来了。

## 三、"不响"的三种用法（全书最重要的技术）

1. **拒绝回答**："侬到底欢喜啥人？"沪生不响。
2. **默认**："我晓得侬心里有我。"她不响。他心里就明白了。
3. **话太多，说不出来**：他把烟点着，抽了半根，还是不响。

一个"不响"，抵三段心理描写。**但一章最多三次**，多了就成套路。

## 四、饭局结构（《繁花》的发动机）

《繁花》里几乎所有大事都发生在饭桌上。一顿饭的结构：

1. **谁请、为什么请、坐哪里**（座位就是权力关系）
2. **点菜**（点贵了点便宜了，都在说话）
3. **席间谁敬谁、谁挡酒、谁说了一句不该说的**
4. **散场时谁送谁、谁没送**
5. **第二天传出来的话，跟当时说的不一样**

一顿饭写三千字，三十年就过去了。

## 五、示范段落（原创，学《繁花》的腔）

> 一九九三年秋天，阿宝请客，请在西区一家本帮馆子，楼上包房，圆台面，十二个人。蓓蒂来得最晚，穿一件墨绿旗袍，进门先看一圈，看到阿宝旁边空着一个位子，就坐下去，也不讲话。
>
> 菜上到第三道，有人讲起股票认购证，讲得眉飞色舞。蓓蒂不响，拿筷子把一只虾的壳剥干净，放到阿宝面前的小碟里。阿宝也不响，吃了。
>
> 散场的时候落雨，阿宝讲，我送侬。蓓蒂讲，勿要，我自己回去。阿宝就站在门口，看她撑开伞，走进雨里，走了十几步，回头看了一下。
>
> 很多年以后阿宝还记得那一下。那天他要是追上去，事情可能不一样。可他没有追。他只是把烟点着，站在屋檐底下，听雨落到半夜。

看到没有：一句"我爱你"都没有。全在剥虾、在空位子、在回头看的那一下。

## 六、禁区（写歪的样子）

- **方言词典**：每段三句上海话，读者直接弃书。
- **纯怀旧散文**：只剩老上海的风情，没有人物、没有算计、没有脏东西。
- **把女性写成符号**：旗袍、香烟、嗲——这不是人物，是布景。
- **解释太多**：写一句"她其实心里很苦"，前面三千字全废。
- **结尾升华**：繁花的结尾永远停在一个动作上，不停在道理上。

## 七、写作前自检（五问）

1. 这一章有没有一顿饭、一次见面、一场雨？（繁花的三个基本场景单位）
2. "不响"用了几次？超过三次就删。
3. 有没有一个物件从头到尾没被解释？（旗袍、伞、一只虾）
4. 方言是不是不超过五处，且一处都没解释？
5. 结尾是停在一个动作上，还是作者跳出来感慨了？
