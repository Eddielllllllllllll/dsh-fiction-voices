# 狂飙笔法

《狂飙》能爆，不是因为案子大，是因为它把一个"卖鱼的"怎么一步步变成"京海的天"，写得让人又恨又懂。

先记住一句：**反派不是坏人，是走错路的普通人。读者要能在他身上看见自己。**

## 一、五条核心气质

1. **三段式时间切片。** 2000 / 2006 / 2021（可自定），每个时间点必须有一次"身份跃迁"：鱼贩→小老板→建工集团董事长→黑老大。三段之间不写过渡，直接切，让观众自己算他这几年干了什么。
2. **双雄对峙。** 一条理想主义的线（安欣：我就要查到底），一条堕落的线（高启强：我只想让家里人过好日子）。两个人的起点都是"好人"，分岔点在某个具体的选择上。
3. **强情节钩子。** 每集一个小钩子，每三集一个大钩子。案子是壳，人性是核。
4. **台词是钩子，不是台词。** 一句话要让观众能复述、能发朋友圈、能当梗。"告诉老默，我想吃鱼了。""风浪越大，鱼越贵。"——台词一出来，人物就立住了。
5. **道德灰度。** 好人也会妥协，坏人也有软肋。最狠的反派，是那个对家人极好的人。

## 二、结构技术

- **三幕式：每个时间点一个"局面"。**
  - 第一幕：底层，被欺负，第一次"不忍了"。
  - 第二幕：崛起，开始用坏手段解决好问题，第一次"回不了头"。
  - 第三幕：巅峰，众叛亲离，第一次"想回头但来不及"。
- **案件驱动：每个阶段一个案子。** 案子要跟主角的利益直接挂钩，不能是"顺便破的"。
- **前史穿插：** 每个重要人物都要有一次"他为什么会变成这样"的闪回，不超过三百字，一次讲完，不重复。
- **对峙戏是重点：** 两个人坐着说话，把枪放在桌上谁也不拿，比打十分钟更紧张。紧张感来自**信息差**和**权力差**。

## 三、台词技术（记忆点怎么造）

三条路：

1. **一句黑话，说一个道理。** "风浪越大，鱼越贵。"——把生意经说成命。
2. **一句威胁，说得很客气。** "告诉老默，我想吃鱼了。"——没有一个狠字，但所有人都知道要死人了。
3. **一句自白，说得很轻。** "我就是想让我弟弟妹妹，能吃上一口热饭。"——反派第一次杀人之后说的，观众就恨不起来了。

规则：**一章最多一句"金句"，且必须是人物的处境自然逼出来的，不是作者硬塞的。**

## 四、人物弧光（怎么写"堕落"）

堕落必须分五步，少一步都不可信：

1. **被欺负**（他不想惹事，事来找他）
2. **第一次越界**（很小的一次，比如收了第一笔不该收的钱）
3. **尝到甜头**（问题真的解决了，他开始觉得"这也没什么"）
4. **第一次杀人/出卖**（他犹豫了，但做了，做完吐了）
5. **合理化**（"我不这么做，我全家都得死"——从此他做什么都不再犹豫）

**关键：每一步都要给他一个"不得不"的理由。读者如果觉得"换我我也可能这么干"，人物就成立了。**

## 五、示范段落（原创，学《狂飙》的写法）

> 二〇〇〇年冬天，高启强还在旧厂街卖鱼，摊位费一个月八十，他交不上，管理的人把他秤给砸了。他蹲下去捡秤砣，捡起来，捏在手里，捏了很久，最后还是放下了。
>
> 三年后，他坐在同一家市场的办公室里，那个砸秤的人站在他对面，给他递烟。他没接，说，坐。那人坐下，屁股只沾了半边椅子。
>
> 高启强给他倒了杯茶，说，以前的事，都过去了。那人赶紧点头。高启强又说，不过有件事我得说清楚——这个市场，以后我说了算。
>
> 他说这话的时候，语气很轻，像在说今天天气不错。那人端着茶杯的手，抖了一下。

看到没有：不写"他变狠了"，写"他语气很轻"；不写"他报复了"，写"那人屁股只沾了半边椅子"。

## 六、禁区（写歪的样子）

- **案件流水账**：一案接一案，人物是工具。案子永远服务于人物，不是反过来。
- **脸谱化反派**：一出场就阴笑、就杀人，读者不会怕，只会觉得假。
- **主角光环**：查案全靠巧合、靠贵人。悬念要靠"他付出的代价"来撑。
- **爽文式打脸**：打完脸就完了。狂飙的爽，爽完是要还的。
- **过度解释时代**：用物件、用物价、用流行歌交代年代，不要用旁白上课。

## 七、写作前自检（五问）

1. 这一章有没有一个"让读者恨不起来"的反派瞬间？
2. 有没有一句能被复述的台词？（没有就删掉重写）
3. 主角这一步"越界"，读者能理解吗？如果不能，理由给够了吗？
4. 三个时间点之间的"身份跃迁"是不是足够大？（不大就没有戏）
5. 章末的钩子，是"事件钩子"还是"人物钩子"？（人物钩子更高级：不是"他会不会死"，是"他还是不是那个人"）
